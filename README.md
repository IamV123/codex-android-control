# Codex 安卓助手 / Codex Android Control

让 Codex 通过你自己的电脑协助操作 Android 手机。**在手机上勾选哪些应用，就允许操作哪些应用；默认一个都不授权。** 无需 root、ADB 或 VPN。

当前版本为 **v0.1.7 实验测试版**，最低 Android 13，按 Android 16 / API 36 编译。电脑重启后可恢复原配对，手机在剩余授权内等待重连；实际操作仍需要手机解锁和两端联网。

[下载 APK 和电脑端包](https://github.com/IamV123/codex-android-control/releases/tag/v0.1.7)

## v0.1.7 改动

- 电脑保存原配对、固定通道和绝对截止时间，程序重启不会换码，也不会延长有效期。Windows 保存内容由当前用户 DPAPI 加密，运行目录限制为当前用户与 SYSTEM。
- 手机在电脑关机或网络中断时保留剩余授权，使用新的连接 ID 和服务端挑战自动重连；不会重发结果未知的操作。锁屏暂停操作，解锁后恢复；停止、到期、更改勾选或停用无障碍仍结束授权。
- 手机授权和新电脑配对可输入整数，选择分钟、小时或天，范围1分钟至30天。实际授权以手机与配对先到期者为准，例如7天授权在重连后继续扣减剩余时间。
- 应用可按名称搜索，每页最多10条，换页与搜索保留勾选。确认、停止及连接状态固定在底部，停止立即显示反馈。保存上次选择只是方便下次勾选，不能自动授权。
- 提供 Windows 当前用户登录后的自动启动和移除脚本，后台恢复同一个通道。免费中继的名字不代表域名所有权或可用性承诺；取得不同地址时拒绝使用，支持接入自己的固定 HTTPS 入口。
- 本地37项 Node 回归、Java授权/定位/手势/时长/分页检查和v3跨语言加密通过；公网模拟验证同地址、同码与原截止时间在程序/通道重启后恢复。真实Windows关机重启、手机长时间后台和新UI需单独验收。

## v0.1.6 改动

- 修复扫码或更改手机授权后重新开始返回 400 的原因：旧版把配对凭证与操作连接合为一体，重新启动会从序号 1 开始，被电脑判为重放。v0.1.5 的复制按钮修复没有覆盖重复扫码路径。
- 配对协议升级为 v2。手机每次本机确认开始都生成新的随机连接 ID，经加密握手建立独立传输密钥和计数器。有效期内同一码可以重复扫码；新的本机授权替换旧连接，旧连接令牌随即失效。
- 同一个握手不能重放，当前连接也不能重用旧序号。若有操作已发出但尚无结果回执，重连和更换二维码均被拒绝，避免丢失未知操作。
- 打开的多个电脑配对页会同步当前二维码；过期后隐藏旧二维码。复制不再无故撤销有效连接，“重新配对”仍会换密钥并撤销旧码。
- 手机 APK 和电脑端均需升级。点按和滑动继续默认使用屏幕触摸。此版已通过本地重连、防重放和跨 Java/Node 加密检查；后续真机已完成同码停止/重新连接、抖音五次上滑和第五个作者主页，以及大众点评搜索、两次上滑和底部店铺详情。

## v0.1.5 改动

- 点击、翻页和滑动默认全部发送屏幕触摸。`phone_click` 用手指点按，`phone_scroll` 和 `phone_swipe` 用手指滑动；不再调用控件的点击或滚动动作，也不会失败后自动补点一次。
- 读屏只用于识别目标和位置。可以直接点按可见的文字或图片区域，不要求应用声明该目标可点击；滑动也不要求区域声明可滚动。
- 点按使用目标可见区域的中心和 80 毫秒按压，滑动使用 320 毫秒手势。完成后重新读屏确认结果；系统回执不能代替业务验收。
- 文字输入保留专门的 `phone_type` 接口，使用 Android 文本写入，不模拟逐个键盘字母触摸。返回、桌面及打开应用仍是导航接口。
- 包含电脑端旧配对码重连修复。已授权应用的范围和会话规则保持不变。

v0.1.4 已在真机用触摸滑动完成五个不同快手视频，并复核淘宝天猫超市商品；停留时间由执行脚本控制，未作独立逐帧计时。v0.1.5 已真机完成小红书三次上滑、打开底部笔记及评论列表；大众点评搜索、两次上滑和店铺点按已生效，详情仍要求用户登录。

## v0.1.4 改动

2026-10-10 电脑端重连修复：main 分支的“复制新配对码”按钮会向电脑获取当前配对信息，已使用过的会话会生成新码，避免旧网页反复复制已用码。重新配对不会打断在途操作；网页会指出旧码重用导致的连接拒绝。此修复兼容手机 v0.1.4，无需重装 APK。

- 新增 `phone_swipe`，通过 Android 触摸手势模拟手指上下左右滑动，适用于快手等原生翻页接口响应不可靠的页面。原有 `phone_scroll` 仍调用控件翻页接口。
- 从刚读取的可见节点选择滑动区域，手机在应用窗口内部生成 320 毫秒手势；电脑不提供任意坐标。手势沿途有其他窗口遮挡时需重新读屏。
- 每次获取前台页面先清理无障碍缓存，并订阅页面内容和滚动事件，避免持续读到同一窗口内的旧内容。
- 手势收到系统完成回调才返回 `performed: true`；这不代表页面一定切换，仍需重新读屏确认。不会自动补发一次手势。

v0.1.3 已在真机完成淘宝输入“卫生纸”、搜索并打开首个标注天猫超市的商品；快手原生翻页未可靠通过。v0.1.4 触摸滑动现已实际改变视频和列表内容。

## v0.1.3 改动

- 已勾选应用可连续读取、点击、输入、滚动，不再逐次弹通知或要求验证锁屏身份。
- 未勾选应用不能读取或操作，返回和回桌面也不再例外。打开应用时检查目标包名是否已授权。
- 不再因支付、红包等页面关键词阻断整个页面；系统标记的密码或敏感文字不回传，节点仍可在应用授权范围内操作。
- 操作使用最新读屏得到的实际节点，刷新目标后执行；不再要求整页文字完全不变。搜索提示词、视频文案等变化不会阻止输入或滚动。
- 修复电脑网页一直显示“正在读取状态”的脚本问题，并显示读取失败原因。

## 授权规则

| 手机状态 | Codex 可以做什么 |
| --- | --- |
| 未开启会话、已锁屏或已过期 | 只能查看电脑侧连接状态 |
| 前台应用未勾选 | 不读取、不点击、不输入、不滚动或滑动，不执行返回或回桌面 |
| 应用已勾选 | 打开应用；在其前台页面读取、点击、输入、滚动、手势滑动、返回、回桌面 |
| 更改勾选、停止会话、停用无障碍或电脑撤销 | 原会话终止，需要重新本机授权；有效配对码可复用 |

应用必须由手机上的人勾选，电脑没有增加授权的接口。手机授权与电脑配对均可自选分钟、小时或天，最长30天，以先到期者为准。开启会话时核对电脑地址并验证一次手机身份；会话内操作不再逐次确认。

小红书、微信、快手、抖音、淘宝和其他可启动应用均可选择。助手本身、系统设置、权限管理、安装器和已识别的安全中心不在可选列表。前台切换到其他应用或系统窗口时，原节点不可继续操作。能否读到和操作某个按钮取决于应用是否提供 Android 无障碍节点。

## 安装与使用

### 手机

1. 下载 `codex-android-control-v0.1.7.apk`，直接覆盖安装旧版，不必卸载。更新后检查本助手的无障碍服务仍已开启。
2. 打开“Codex 安卓助手”，允许通知，并在 Android 设置内手动启用无障碍服务。若系统显示受限设置，请按设备官方说明处理。
3. 刷新电脑配对页，复制整段配对码到手机 App。也可使用支持自定义链接的系统扫码功能。同一码在有效期内可再次本机确认开始；升级时需要新版电脑页的 v3 码。
4. 搜索或换页勾选应用，输入时长并选择分钟、小时或天，点底部“确认并开始”，核对连接地址与有效时长，验证身份。
5. 等到显示“已连接电脑”，保持手机解锁，即可让 Codex 操作已勾选应用。无需逐次确认。
6. 用完点底部或通知中的“立即停止”。锁屏只暂停操作，授权时间继续扣减。手机重启或连接服务被系统结束，需要再次本机授权；本版没有手机开机自动授权。

### Windows 电脑

1. 安装 [Node.js](https://nodejs.org/) 22 或更高版本，以及已登录的 Codex。
2. 解压 `codex-android-control-v0.1.7-desktop.zip` 到固定目录。
3. 双击 `Start-Desktop.cmd`。首次运行安装锁定版本的二维码依赖，连接就绪后打开本机配对网页。
4. 首次运行 `Connect-Codex.ps1`，然后重开 Codex 聊天或应用，载入 `android_control` MCP。脚本不会覆盖已有同名配置。
5. 如需电脑重启后自动恢复，双击 `Enable-AutoStart.cmd`，它只添加当前Windows用户的一个登录启动项；登录同一个Windows用户后运行，不设置自动登录，也不修改其他启动项。撤销自动启动使用 `Disable-AutoStart.cmd`。
6. 手机连接后可以说：“打开我授权的快手”“在淘宝搜索卫生纸”。

更新电脑端时先确认没有未完成操作并停止原进程，替换新版源文件；保留原Codex配置和 `.runtime` 私有目录。v0.1.6升级到v0.1.7需要新的v3码授权一次，此后正常电脑端重启复用原配对，不用再扫码。不要在已发出操作且尚无回执时强行更新。不要将配对码或二维码发到聊天或公开截图。

电脑与手机不必使用同一Wi-Fi。默认LocalTunnel为每台安装保留随机固定名字与已验证的中继分配，重启先接回原通道；原分配失效后只申请同名地址，不接受悄悄换名。该免费服务不保证名字可用性或保留权，[官方说明](https://github.com/localtunnel/localtunnel#options)也注明指定名字受可用性影响。手机到中继使用HTTPS，电脑到中继使用TCP，正文另用端到端加密。正式固定入口可设置 `CAC_PUBLIC_ORIGIN` 并只代理手机端口 `127.0.0.1:18766`；管理端口18765与后台防重复启动端口18764不可暴露。Cloudflare Quick Tunnel只可在 `CAC_TEMPORARY_TUNNEL=1`、`CAC_TUNNEL_PROVIDER=cloudflare` 测试模式使用，不能用于跨重启续接。

电脑端暂时关闭、关机或断网会暂停连接，原授权继续计时；要撤销请用手机停止或电脑网页“立即撤销”。电脑恢复后手机会自动重连，不会重新执行中断时结果未知的操作。手机返回了该操作的完成回执时可以恢复；缺少回执会显示阻塞，需核对实际手机结果后在电脑页解除。移除 MCP 使用 `codex mcp remove android_control`，不影响其他 MCP。

## 数据与权限

- 授权应用里的按钮没有页面关键词限制，执行什么操作仍由用户的具体任务决定。应用选择是本项目的运行时校验，不是 Android 为无障碍服务提供的独立应用沙箱，也不是绝对安全保证。
- 已授权页面的文字会到达电脑和所用 AI 服务；系统标记的密码或敏感节点文字被省略，但无法保证识别全部隐私。
- 手机只主动连接 HTTPS，不开监听端口、不占用 VPN。HKDF-SHA256 派生认证及加密密钥，AES-256-GCM 绑定会话、方向和递增序号；拒绝篡改和重放。
- 手机授权与密钥仅保存在连接服务内存。断线保持剩余授权并重连，锁屏暂停控制；停止或服务被结束后不自动授权。电脑配对信息与恢复日志由当前Windows用户DPAPI加密保存；本地管理状态文件仍包含管理密钥，目录ACL限制访问。
- 不包含截图、录屏、通知读取、剪贴板、文件浏览、相机、麦克风、任意坐标点击、Shell、ADB 或系统设置写入接口。
- 公共中继能观察部分连接元数据和派生的传输凭据；加密内容与配对主密钥的边界见 [SECURITY.md](SECURITY.md)。

## 构建与验证

工具链：JDK 17、Android SDK Platform 36、Build Tools 36.0.0、Gradle 9.1.0、AGP 9.0.0。

```powershell
cd desktop
npm ci --ignore-scripts
npm test
cd ..
node tools/test-cross-crypto.mjs
.\gradlew.bat :app:assembleRelease :app:lintRelease
```

未设置签名环境变量时输出 unsigned APK。发布包使用同一项目 release 签名，`debuggable=false`。签名变量为 `CAC_KEYSTORE`、`CAC_STORE_PASSWORD`、`CAC_KEY_PASSWORD`，别名 `release`。密钥不进入源码和发布包。

[验证记录](docs/VALIDATION.md) 区分自动测试、公网模拟和真实手机操作。项目尚未接受独立安全审计。

这是独立实现，设计时参考 [codex-control-android-mcp](https://github.com/miko684/codex-control-android-mcp) 和 [android-use](https://github.com/bsaisuryacharan/android-use) 的公开方案，没有复制其实现。二维码依赖 `qrcode`，可选隧道程序来自 Cloudflare 官方发行版。
