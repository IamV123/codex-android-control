## v0.1.5 真机验收

1. 勾选一个应用，保持手机解锁；确认读屏、点击、输入和滚动无需逐次批准。
2. 切换到未勾选应用，确认读屏、节点操作、返回和桌面动作均拒绝；打开已勾选应用仍可执行。
3. 点击和翻页默认产生触摸，不依赖应用的控件点击或滚动实现。大众点评选择底部店铺的可见标题点按，核对实际进入详情；小红书三次上滑后打开底部内容及评论。快手触摸滑动须核对作者或内容变化，不能只根据手势回执计数。
4. 点击目标本身被替换、窗口切换或节点已失效时，要求重新读屏。
5. 锁屏、取消勾选、停止、电脑撤销或到期后应终止控制。
6. 网络中断导致结果未知时，检查实际手机状态；不自动重放。

本地回归不覆盖 Android 实际窗口与 AccessibilityNodeInfo 的厂商差异。五个短视频的停留时间与天猫超市商品选择，需要在真机任务执行后单独报告。

## 电脑端重连修复

本地复现：同一码成功连接后，用新的加密 nonce 从序号 1 重新开始，被防重放校验拒绝（HTTP 400）。新复制按钮创建新会话后，第一个手机请求从序号 1 正常连接。旧浏览器页面会从服务器取得当前码，剪贴板不可用时也会显示新码供手动复制。在途命令存在时，复制新码和重新配对均返回 409，原会话继续保留。

修复后真机使用新码重新连接成功，四个已选应用在后续浏览中持续连接，未再次报告 HTTP 400。此前用户收到的 400 没有同步取得失败分类，因此不能确定全部由旧码重用引起。
